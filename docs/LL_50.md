# LL-50: strategy comparisons in CI

Implemented October 25, 2026. No simulation change (engine stays **0.25.0**).

## What runs

`npm run test:comparisons` (`npm run sim -- compare --ci`) runs the LL-10 suite (7 comparisons, 19 variants, 3 sites, Standard plus Real seeds 1–3) under two profiles:

| Profile | Rules | Report |
|---|---|---|
| New-game | what a new game sets (`NEW_GAME_SETTINGS`) | `docs/PHASE_4_COMPARISONS.md` |
| Experimental | the same plus all twelve opt-in mechanics under Settings → Experimental mechanics | `docs/PHASE_4_COMPARISONS_EXPERIMENTAL.md` |

The second profile is the point of "a gated mechanic": a new game leaves every gate off, so a change to, say, finance or transport access never moves the new-game report. With every gate on, it does.

It fails when:

1. a committed report differs from the one the current code writes (regenerate and commit it);
2. a **headline outcome** differs from `docs/comparisons/headlines.json`;
3. the committed headlines' digest has no note in `docs/COMPARISON_NOTES.md`, or the note still says TODO.

Headlines are what a player would notice, per profile, comparison, variant and weather: runs with a departure, median survival-short days, median lowest wellbeing, median end cash to the nearest $100, median home-grown share to the nearest percent. Gift values, labor hours and pantry days are report-only: a stale report fails, but regenerating it needs no note.

`npm run test:comparisons -- --update` rewrites both reports and the headlines, prints which headlines moved, and appends a stub under `## <digest> — engine <version>` listing them with `Why: TODO`. The check passes once that TODO is replaced with an explanation.

## Where it runs

- `.github/workflows/nightly.yml`: every night at 07:17 UTC and on demand. On a failure it regenerates and uploads the reports, headlines and notes as an artifact, so the diff can be reviewed without a local run.
- `packages/cli/test/compare.test.ts` (every push): the committed headlines match their digest and have a finished note; headlines ignore gift prices but catch cash and departures; the note lookup only matches a heading; the experimental profile turns on exactly the mechanics a new game leaves off.
- The full suite takes about 15 seconds locally (both profiles), so it could join PR CI later.

## Baseline

The first run caught real drift: the committed new-game report showed tutorial gifts worth $3,248, but Phase 10 catalog rows had moved them to $3,273. No new-game headline had changed. The experimental profile's first findings, recorded in the baseline note: everyone stays home on every route except Laramie's paid crew for a late heater (15 days in town, Standard and Real seed 1); home-grown food drops to 12–13% from 19–22%.

## Limits

Headlines are medians, so a single bad seed moves only the departure count. The experimental profile turns every gate on at once; it says that something moved, not which gate moved it (the per-ticket `docs/LL_3x_COMPARISONS.md` reports do that). The nightly job reports; it does not commit.
